# 새싹살롱 진행판

술 없는 로테이션 소개팅 **새싹살롱**을 진행하는 웹앱입니다.
호스트는 태블릿이나 폰으로 모임을 진행하고, 참가자는 각자 폰으로 입장 코드를 넣어 참여합니다.

- 앱 주소: https://undergrovecafe.github.io/saessak-salon/
- 호스트 바로가기: https://undergrovecafe.github.io/saessak-salon/#host

## 호스트 화면

| 탭 | 하는 일 |
| --- | --- |
| 참가자 | 입장 코드와 QR 표시, 식물 닉네임·성별 등록, 입장 여부 확인 |
| 로테이션 | 라운드 타이머(참가자 폰과 동기화), 라운드별 자리 배치 |
| 게임 | OO라면?, 텔레파시 게임, 진실 혹은 새싹, 나와 닮은 식물 카드 뽑기 |
| 물방울 시그널 | 참가자가 보낸 물방울 수 확인(보낸 사람은 비공개), 참가자에게 공개 여부 |
| 최종 선택 | 제출 현황, 폰이 없는 참가자 대신 입력 |
| 결과 공개 | 매칭 결과 확인, 참가자 폰에 결과·이미지 카드 공개 |

## 참가자 화면

입장 코드 4자리를 넣거나 호스트 화면의 QR을 찍고, 명찰의 식물 닉네임을 고르면 시작됩니다.

| 탭 | 하는 일 |
| --- | --- |
| 지금 | 내 테이블·자리, 마주 앉은 사람, 남은 시간 |
| 물방울 | 마음 가는 사람에게 물방울 최대 3개 보내기 (익명) |
| 이미지 카드 | 상대별 외적·내적 이미지와 한 줄 응원 쓰기 (익명) |
| 최종 선택 | 1·2지망 제출 (제출 후 수정 불가, 호스트는 수정 가능) |
| 결과 | 호스트가 공개하면 내 매칭 결과와 받은 이미지 카드 확인 |

## 데모 모드와 Firebase

`config.js`가 비어 있으면 **데모 모드**로 동작합니다. 데모 모드는 한 기기의 한 브라우저 안에서만 공유돼요.
같은 브라우저에서 탭을 여러 개 열면 탭마다 다른 참가자처럼 시험해 볼 수 있습니다.

여러 사람의 폰을 연결하려면 Firebase(무료)를 연결하세요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** → 이름 `saessak-salon` → Google 애널리틱스는 꺼도 됩니다.
2. 왼쪽 **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 **싱가포르(asia-southeast1)** → **잠금 모드로 시작**.
3. **규칙** 탭에 이 저장소의 `database.rules.json` 내용을 붙여넣고 **게시**.
4. 톱니바퀴 **프로젝트 설정 → 내 앱 → 웹(</>)** 으로 앱 등록 → 나오는 `firebaseConfig` 값을 `config.js`에 붙여넣기.
   `databaseURL` 항목이 꼭 있어야 합니다.
5. 저장소에 커밋하면 1~2분 뒤 반영됩니다.

Firebase 웹 설정값(apiKey 등)은 원래 공개되는 값이라 저장소에 올려도 괜찮습니다.

## 개인정보와 보안

- 입장 코드를 아는 사람은 그 모임 데이터를 읽고 쓸 수 있습니다. 실명·연락처는 넣지 말고 식물 닉네임만 쓰세요.
- 모임이 끝나면 호스트 화면 **참가자 → 모임 종료 · 데이터 삭제**로 기록을 지워주세요.

## 파일 구조

```
index.html           배포되는 앱 (build.sh로 생성)
src/app-body.html    앱 본문 (수정은 여기서)
config.js            Firebase 연결 설정
database.rules.json  Firebase 보안 규칙
build.sh             src/app-body.html → index.html 변환
```

질문 카드와 게임 문구는 `src/app-body.html`의 `DECKS`에서 바꿀 수 있고, 수정 후 `./build.sh`를 실행하면 됩니다.

## GitHub Pages

저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장하면 배포됩니다.
