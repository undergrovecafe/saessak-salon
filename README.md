# 새싹살롱 진행판

술 없는 로테이션 소개팅 **새싹살롱**을 호스트가 태블릿이나 휴대폰 한 대로 진행하기 위한 웹앱입니다.
서버 없이 브라우저만으로 동작하고, GitHub Pages로 무료 배포할 수 있습니다.

## 기능

| 탭 | 하는 일 |
| --- | --- |
| 참가자 | 식물 닉네임과 성별 입력 (성별당 최대 6명) |
| 로테이션 | 라운드 타이머(기본 10분, 종료 시 알림음), 라운드별 테이블·자리 자동 배치 |
| 게임 | OO라면?, 텔레파시 게임, 진실 혹은 새싹, 나와 닮은 식물 카드 뽑기 |
| 물방울 시그널 | 참가자별 받은 물방울 수 기록, 숫자 가리기 |
| 최종 선택 | 참가자가 한 명씩 1·2지망 입력 (저장하면 입력칸이 비워짐) |
| 매칭 결과 | 서로 선택한 쌍 자동 계산, 중복 매칭 표시 |

자리 배치 규칙: 여성은 자리 1~6에 고정, 남성은 라운드마다 한 칸씩 이동합니다. 테이블 1이 자리 1~3, 테이블 2가 자리 4~6입니다.
인원이 맞지 않으면 빈자리나 휴식으로 표시됩니다.

## 데이터 저장

입력한 내용은 **사용하는 기기의 브라우저에만** 저장됩니다(localStorage).
다른 기기와 공유되지 않으니 진행은 한 기기로 해 주세요. 모임이 끝나면 참가자 탭의 **전체 초기화**로 지워 주세요.

## 파일 구조

```
index.html          배포되는 앱 (build.sh로 생성)
src/app-body.html   앱 본문 (수정은 여기서)
build.sh            src/app-body.html → index.html 변환
```

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 올립니다.
   ```
   git remote add origin https://github.com/<아이디>/<저장소이름>.git
   git push -u origin main
   ```
2. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

## 수정하기

질문 카드, 게임 문구는 `src/app-body.html`의 `DECKS` 부분에서 바꿀 수 있습니다.
수정 후 `./build.sh`를 실행하면 `index.html`이 다시 만들어집니다.
